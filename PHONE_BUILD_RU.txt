СБОРКА APK ТОЛЬКО С ТЕЛЕФОНА (через GitHub Actions)

1. Открой github.com в Chrome и войди/создай аккаунт.
2. Создай новый пустой репозиторий (New repository), например criminal-city-rp.
3. Распакуй ZIP в телефоне. Загрузи СОДЕРЖИМОЕ папки CriminalCityAndroid в корень репозитория. Важно: вместе с папками app, .github и файлами build.gradle, settings.gradle.
4. Открой вкладку Actions репозитория. Если GitHub попросит разрешить Actions, подтверди.
5. Если загрузка файлов была в main, workflow должен запуститься автоматически. Если нет: Actions -> Build Criminal City RP APK -> Run workflow.
6. Дождись зелёной галочки. Открой запуск workflow -> внизу Artifacts -> Criminal-City-RP-debug-apk и скачай ZIP.
7. Распакуй скачанный ZIP, найди app-debug.apk и нажми на него для установки. Если Android спросит, разреши установку из Chrome/Файлов только для этого источника.

ПРИМЕЧАНИЯ
- Для загрузки файлов и сборки нужен интернет и бесплатный аккаунт GitHub.
- Это APK-оболочка WebView для текущей HTML-игры, а не нативный 3D-порт GTA.
- Для Three.js и внешних ресурсов при запуске нужен интернет.
- Система claude.use('room') не превращается в публичный онлайн-сервер автоматически.
